# Pet Battle Tycoon

A simulator/tycoon fusion for Roblox: roll pets from a gacha, send them out to auto-battle
NPCs in three combat zones for cash and gem drops, then spend that cash back at your own
tycoon base to unlock more pet slots, damage/cash multipliers, and reroll machines for your
pets' race and trait.

Everything — the map, tycoon bases, NPCs, and UI — is generated by scripts at server start,
so there's no place file to open; sync this repo straight into an empty Roblox place with
[Rojo](https://rojo.space/) and press Play.

## How it plays

- **Gacha**: walk up to the pink Gacha Machine near spawn (or use the "Gacha" HUD button)
  and roll for $100. Each roll gives a pet species (rarity-weighted), a **race** (Normal /
  Golden / Rainbow / Shiny — a stat multiplier) and a **trait** (Neutral / Swift / Tanky /
  Lucky / Greedy — a secondary modifier).
- **Combat**: equipped pets automatically orbit you and attack the nearest NPC within range
  whenever you're near one of the three zones (Slime Fields, Goblin Camp, Dragon's Lair —
  increasing difficulty and rewards). Damage dealt earns cash immediately; killing an NPC
  also has a chance to drop gems.
- **Tycoon base**: on join you're assigned one of six bases. Click the glowing buttons on
  your base to spend cash on upgrades — more equipped pet slots, damage/cash multipliers,
  passive cash droppers, and unlocking the Race/Trait reroll machines.
- **Rerolling**: once unlocked, click the pink (race) or blue (trait) machine on your base
  to spend gems re-rolling a chosen pet's race or trait.

## Project layout

```
src/
  ReplicatedStorage/Modules/   -- shared config & data tables (rarities, pets, NPCs, upgrades)
  ServerScriptService/         -- Main.server.lua bootstraps every service in Services/
    Services/
      DataService.lua          -- DataStore load/save (Cash, Gems, Pets, Upgrades, ...)
      GachaService.lua         -- weighted pet/race/trait rolls
      PetService.lua           -- equip/unequip, reroll, effective combat stats
      TycoonService.lua        -- plot assignment, upgrade purchases, passive income
      CombatService.lua        -- NPC spawning/respawning, pet AI, damage & rewards
      MapBuilder.lua           -- procedurally builds the baseplate, bases, and zones
  StarterPlayer/StarterPlayerScripts/
    Main.client.lua            -- wires remotes to the UI
    UI/                        -- HUD, Gacha, Inventory, and Reroll panels (built in code)
```

## Running it

1. Install [Rojo](https://rojo.space/) (plugin + CLI) if you haven't already.
2. From this repo: `rojo serve`
3. In Roblox Studio, open a new empty place, connect the Rojo plugin, and sync.
4. Press Play. A map, 6 bases, a gacha machine, and 3 combat zones are built automatically.

## Known limitations (intentional for a first playable build)

- Player data uses plain `DataStoreService` calls with no session-locking, so joining the
  same account on two servers at once can lose progress — fine for a single-server test,
  worth swapping for a library like ProfileService before a real launch.
- Only 6 tycoon bases exist; a 7th concurrent player can still gacha/battle but won't get a
  base until one frees up.
- Pets have no leveling/fusion system yet — power currently comes from rarity, race, trait,
  and tycoon upgrades only.
- All visuals (pets, NPCs, bases) are primitive parts, not modeled/animated characters —
  easy to swap for real models later since everything is built from data tables.

## Extending it

Most content lives in plain data tables, so adding content doesn't require touching game
logic:

- New pets: add an entry to `PetDatabase.lua`.
- New combat zones/NPCs: add an entry to `NPCDatabase.lua`.
- New tycoon upgrades: add an entry to `GameConfig.TycoonUpgrades` with an `effect.type` of
  `petSlot`, `damageMult`, `cashMult`, `unlock`, or `passiveIncome`.
